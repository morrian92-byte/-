# 关系网络系统

> **Status**: In Design
> **Author**: Player + Claude
> **Last Updated**: 2026-06-09
> **Implements Pillar**: 关系即游戏（关系网络是官场博弈的真正棋盘）

> **Quick reference** — Layer: `Core` · Priority: `MVP` · Key deps: `时间系统`, `NPC 系统`

## Overview

关系网络系统管理玩家与每个 NPC 之间的态度值——这不是一个简单的「好感度」，而是一个反映利益、情感和权力动态的复杂指标。每个 NPC 对你的态度从 -100（死敌）到 +100（铁杆盟友），由你的行为、时间流逝和事件共同塑造。

这个系统是支柱二「关系即游戏」的技术实现。关系不是附属系统——它就是游戏本身。你在官场中的每一个机会、每一条信息、每一次危机，都和你与关键人物的关系直接相关。

## Player Fantasy

你打开关系网络，看到上面 10 个人的头像。张书记对你的态度是 +35，颜色是偏绿的黄——还行，但不够铁。李副书记是 -15，偏红的橙色——上次你拒绝他的要求后，他一直没缓过来。王镇长是 +72，绿色——你帮他争取过项目经费，他是你的贵人。

你决定这个月请张书记吃顿饭（财力 -15，态度预判 +3~5），顺便给李副书记送条烟（财力 -8，态度预判 +5~10，但他性格「正直」可能拒收）。关系需要经营，而每个月你只有有限的精力和财力。选择谁、怎么选——这就是官场。

## Detailed Design

### Core Rules

**R1 — 态度值范围**：每个 NPC→玩家的态度值在 -100 到 +100 之间。正值表示好感/支持，负值表示反感/敌意。

**R2 — 态度层级**：

| 范围 | 标签 | 颜色 | NPC 行为倾向 |
|------|------|------|------------|
| +80 到 +100 | 铁杆 | 深绿 | 主动帮你、为你说话、在关键时刻力挺 |
| +50 到 +79 | 友好 | 绿色 | 愿意帮忙、分享信息、有利推荐 |
| +20 到 +49 | 善意 | 浅绿 | 基本的善意，不主动为难 |
| -19 到 +19 | 中性 | 灰色 | 公事公办，没有特别倾向 |
| -20 到 -49 | 冷淡 | 橙色 | 不太配合，可能有小动作 |
| -50 到 -79 | 敌意 | 红色 | 主动制造障碍，背后捅刀 |
| -80 到 -100 | 死敌 | 深红 | 不惜代价打压你 |

**R3 — 态度变化来源**：

| 行为/事件 | 方向 | 幅度 | 说明 |
|----------|------|------|------|
| 主动社交（请客/拜访） | + | +3~8 | 每月可做，有财力消耗 |
| 送礼 | + | +5~15 | 受 NPC 性格影响（正直者可能拒收甚至扣分） |
| 帮 NPC 办事 | + | +8~20 | 完成 NPC 的请求——最有效的加分方式 |
| 在会议上支持 NPC 的意见 | + | +3~5 | 公开站队 |
| 拒绝 NPC 的请求 | - | -5~15 | 视请求的重要性 |
| 公开反对 NPC | - | -10~20 | 公开对立影响大 |
| 举报/揭发 NPC | - | -20~40 | 直接跳到敌意 |
| 晋升后 NPC 变下属 | +/- | ±10~20 | 视 NPC 性格——嫉妒者扣分，务实者加分 |
| 自然衰减 | - | -1~3/月 | 不维护的关系随时间冷却 |
| 重大事件影响 | +/- | ±10~30 | 巡视、事故等事件波及 |

**R4 — 自然衰减**：
- 每个月结束时，所有 NPC 的态度值向中性（0）方向衰减。
- 衰减速率：默认 -2/月，但受以下因素影响：
  - 最近 3 个月内有正面互动：衰减减半（-1/月）
  - 最近 3 个月内有负面互动：衰减为零（关系定格，好或坏）
  - NPC 性格「记仇」：负面态度不衰减
  - NPC 性格「感恩」：正面态度衰减减半

**R5 — 态度阈值效应**：
- 上级态度 ≥ +50：可能获得晋升推荐
- 上级态度 ≥ +20：正常的工作关系
- 上级态度 ≤ -20：可能被穿小鞋
- 同级态度 ≥ +50：可能形成联盟
- 下属态度 ≥ +50：工作积极，可能主动帮你挡事
- 下属态度 ≤ -30：工作消极，可能成为举报人

**R6 — 关系网络聚合**：
- 所有 NPC 态度值的加权平均 = 人脉资源的基础值
- 权重基于 NPC 的职级（上级权重高）和互动频率
- 人脉值每月根据关系网络重新计算

### States and Transitions

对于每对玩家-NPC关系：

```
NEUTRAL ──(positive actions)──> POSITIVE
NEUTRAL ──(negative actions)──> NEGATIVE
POSITIVE ──(neglect/time)──> NEUTRAL
NEGATIVE ──(reconciliation)──> NEUTRAL
POSITIVE ──(betrayal)──> NEGATIVE (jump, not decay)
```

**翻面事件**（态度大幅跳变）：
- 你帮 NPC 摆平了大麻烦：+30 到 +50
- 你出卖了 NPC：-40 到 -60
- NPC 发现你举报了他：-60 到 -80
- 你在关键时刻力挺 NPC：+25 到 +40

### Interactions with Other Systems

| 交互方 | 方向 | 内容 |
|--------|------|------|
| 时间系统 | 关系→时间 | 每月 tick 触发自然衰减 |
| NPC 系统 | 关系→NPC | 读取 NPC 性格标签影响态度变化规则 |
| 资源系统 | 双向 | 财力用于社交→提升关系；关系值贡献人脉资源 |
| 事件系统 | 双向 | 关系值影响事件选项和结果；事件结果改变关系值 |
| 晋升系统 | 关系→晋升 | 关键上级态度是晋升条件之一 |
| 灰色地带系统 | 双向 | 关系好的人可能提供腐败机会；腐败行为改变关系 |
| 主面板 UI | 关系→UI | 供关键 NPC 态度摘要 |
| 关系网络 UI | 关系→UI | 供完整关系网络视图（VS+） |

## Formulas

### 态度变化计算

```
attitude_change = sum(action_effects) + decay + event_impact

// 有上限和下限
new_attitude = clamp(current_attitude + attitude_change, -100, 100)
```

### 自然衰减（每月）

```
function monthlyDecay(npc, current_attitude):
    base_decay = current_attitude > 0 ? -2 : +2  // 向0衰减
    if npc.has_recent_interaction(3_months): base_decay *= 0.5
    if npc.personality.includes("记仇") && current_attitude < 0: return 0
    if npc.personality.includes("感恩") && current_attitude > 0: base_decay *= 0.5
    return base_decay
```

### 人脉聚合值

```
connections_aggregate = weighted_average(all_npc_attitudes, weights)
// weights = npc.rank_level / sum(all_ranks) * interaction_frequency_factor
```

## Edge Cases

| Scenario | Expected Behavior | Rationale |
|----------|------------------|-----------|
| 玩家对所有 NPC 态度都很低 | 人脉资源归零，事件中孤立无援，晋升无望 | 官场「社死」了 |
| NPC 死亡/调离 | 该关系从网络中移除，人脉值重新计算。如果此人是关键上级，晋升通道暂时受阻 | 关系不永存 |
| 玩家试图同时讨好对立派系的 NPC | 两个派系的 NPC 对你的态度增长都会打折（-30%）。骑墙不是免费午餐 | 真实的站队困境 |
| 态度达到极值（±100） | 不再继续增长/减少。但需要持续维护——长期不维护仍会衰减 | 再铁的关系也会因忽视而冷淡 |

## Dependencies

| System | Direction | Nature of Dependency |
|--------|-----------|---------------------|
| 时间系统 | 关系依赖时间 | 每月 tick 触发衰减 |
| NPC 系统 | 关系依赖 NPC | 读取 NPC 属性影响态度计算 |
| 资源系统 | 双向依赖 | 消耗财力提升关系；关系值贡献人脉资源 |

## Tuning Knobs

| Parameter | Default | Safe Range | Effect of Increase | Effect of Decrease |
|-----------|---------|------------|-------------------|-------------------|
| 每月衰减速率 | 2/月 | 1-5/月 | 关系冷得更快——社交压力大 | 关系持久——官场更稳定 |
| 社交态度提升 | +3~8 | +1~15 | 社交更有效 | 社交效果微弱 |
| 送礼提升 | +5~15 | +3~25 | 送礼更有效——更像「金钱政治」 | 送礼效果微弱——更看重实干 |
| 衰减减半窗口 | 3个月 | 1-6月 | 维护关系更轻松 | 需要更频繁地互动 |
| 骑墙惩罚 | -30% | -10%~-50% | 同时讨好对立阵营更难 | 骑墙更可行 |

## Acceptance Criteria

- [ ] 每个 NPC 对玩家的态度值可正确追踪（-100 到 +100）
- [ ] 态度变化来源正确：社交、办事、送礼、拒绝、时间衰减
- [ ] 自然衰减按规则执行，受 NPC 性格影响
- [ ] 态度层级判定正确（铁杆/友好/善意/中性/冷淡/敌意/死敌）
- [ ] 人脉资源值正确聚合自所有 NPC 态度
- [ ] 关系数据可正确序列化到存档
- [ ] 送礼被正直 NPC 拒收时，态度不升反降
