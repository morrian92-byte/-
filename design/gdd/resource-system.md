# 资源系统

> **Status**: In Design
> **Author**: Player + Claude
> **Last Updated**: 2026-06-09
> **Implements Pillar**: 权力是积累的（资源是权力积累的具体载体）

> **Quick reference** — Layer: `Core` · Priority: `MVP` · Key deps: `时间系统`

## Overview

资源系统定义了《步步高升》中三个核心资源的产出、消耗、上限和互相转化规则。这三个资源——政绩、人脉、财力——是玩家每个月经营决策的直接对象，也是所有其他系统判断「玩家处于什么状态」的基础数据。

三个资源构成一个不可能三角：专注于一个必然削弱另外两个。资源系统不决定玩家怎么分配行动（那是月度经营系统的职责），但它定义了每个资源的存在方式和变化规则。

## Player Fantasy

打开你的面板，三个数字摆在你面前。政绩 78，人脉 45，财力 320。上个月修路花了 100，政绩涨了 5 点。上周请王副局长吃饭花了 30，人脉涨了 3 点。

你看一眼就知道自己现在的处境——政绩够高，上面看你的眼神不一样。人脉偏低，有些消息别人不告诉你。财力还行，但年底的考核项目还差一大截。你需要做选择，而这个月你只有这么多精力。

数字不是冰冷的。每一个点的涨跌背后都有具体的事件和人物。政绩 -10 意味着你负责的项目出了事故。人脉 +20 意味着你刚攀上了一个关键人物。这些数字是你仕途的血肉。

## Detailed Design

### 三大核心资源

| 资源 | 含义 | 范围 | 产出方式 | 消耗方式 | 玩家感受 |
|------|------|------|---------|---------|---------|
| **政绩** | 政治资本——你的治理成果和上级对你的认可 | 0–100 | 完成项目、达成指标、获得表彰 | 项目失败、事故、被问责、用来「摆平」麻烦 | 「我干得好不好？」 |
| **人脉** | 关系网络——你在官场中有多少人愿意帮你 | 0–100 | 维护关系、帮人办事、站队成功 | 请人帮忙、自然衰减、得罪人 | 「我认识谁？谁欠我人情？」 |
| **财力** | 可支配资金——你能调动的经济资源 | 0–N | 常规预算、项目拨款、灰色收入 | 项目支出、人情往来、被罚款/退赃 | 「我手上有多少钱可以花？」 |

### 政绩细则

**产出公式**（每月）：
```
performance_change = project_completion_bonus + target_achievement_bonus - incident_penalty
```

| 来源 | 数值 | 触发条件 |
|------|------|---------|
| 项目完成 | +5 到 +20 | 取决于项目规模和完成质量 |
| 季度指标达标 | +3 到 +8 | 季度考核时，每项达标指标 |
| 年度评优 | +10 到 +25 | 年度考核评级「优秀」 |
| 上级表扬 | +2 到 +5 | 关系好的上级在适当场合提及 |
| 项目失败 | -5 到 -15 | 项目延期或失败 |
| 安全事故/舆情 | -10 到 -30 | 重大负面事件 |
| 问责/处分 | -20 到 -40 | 正式问责或处分决定 |
| 自然衰退 | 0 | 政绩不自然衰退，但久不出成绩会被认为「啃老本」 |

**政绩阈值效应**：

| 政绩范围 | 状态 | 影响 |
|---------|------|------|
| 0–20 | 危险 | 容易被问责调离，晋升无望 |
| 21–40 | 警告 | 考核勉强过关，上面开始注意 |
| 41–60 | 合格 | 正常运转，没有亮点也没有大问题 |
| 61–80 | 良好 | 上下看好，晋升有力 |
| 81–100 | 卓越 | 明星干部，破格提拔候选 |

### 人脉细则

**产出公式**（每月）：
```
connections_change = monthly_relationship_maintenance + favor_balance - natural_decay - offense_penalty
```

| 来源 | 数值 | 触发条件 |
|------|------|---------|
| 关系维护（日常） | +1 到 +3 | 每月花时间社交（吃饭、拜访、电话） |
| 帮人办事 | +3 到 +8 | 成功帮某个 NPC 解决问题 |
| 站队正确 | +5 到 +15 | 在派系博弈中站对了方向 |
| 提拔他人 | +5 到 +10 | 推荐的人获得晋升（你有「你的人」上去了） |
| 自然衰减 | -1 到 -3/月 | 长期不维护的关系会冷却 |
| 得罪人 | -5 到 -20 | 举报、拒绝帮忙、公开唱反调 |
| 求人办事 | -3 到 -10 | 消耗人情——让人帮忙需要代价 |

> **注意**：人脉是一个**聚合值**，它反映的是你整体的人脉广度。个别 NPC 的态度值由关系网络系统管理。人脉值高意味着你有很多「门路」可选，但它不替代关系网络系统的细粒度 NPC 态度。

### 财力细则

**产出公式**（每月）：
```
budget_change = monthly_allocation + project_funding + gray_income - project_spending - social_spending - penalty
```

| 来源/支出 | 数值 | 说明 |
|----------|------|------|
| 月度常规预算 | +10 到 +50 | 取决于职级和岗位（股级20→科级40→处级80等） |
| 项目专项拨款 | +20 到 +200 | 一次性，立项时发放 |
| 灰色收入 | +5 到 +∞ | 不确定，取决于灰色地带系统的机会和你的选择 |
| 项目支出 | -10 到 -100 | 推进项目需要花钱 |
| 人情往来 | -5 到 -30 | 请客、送礼、打点关系 |
| 退赃/罚款 | -全部灰色收入或更多 | 被查时的代价 |

财力的上限不做硬性限制，但极端财富（远超岗位正常收入）会在灰色地带系统中增加风险。

### 三个资源的互转

资源之间可以有限转化，但有效率损耗：

| 转化 | 比率 | 损耗 | 含义 |
|------|------|------|------|
| 财力 → 人脉 | 1 点人脉 ≈ 10-30 财力 | — | 请客送礼、人情往来 |
| 财力 → 政绩 | 1 点政绩 ≈ 15-50 财力 | — | 投入项目、自掏腰包补缺口 |
| 人脉 → 政绩 | 1 点政绩 ≈ 3-5 点人脉 | — | 找人帮忙推进项目、借力完成任务 |
| 人脉 → 财力 | 1 点财力 ≈ 0.5-1 点人脉 | — | 通过关系争取更多预算 |
| 政绩 → 人脉 | 间接 | — | 做出成绩吸引别人主动结交 |
| 政绩 → 财力 | 间接 | — | 好成绩带来更多项目经费 |

### MVP 简化

MVP 阶段，资源系统的实现重点：
- 三个资源的数值追踪和范围约束
- 基础的月度结算公式
- 政绩阈值效应（影响 NPC 态度和晋升资格）
- 灰色收入暂用简化模型（固定事件触发，不做动态生成）

## Formulas

### 月度资源结算

```
// 每月 tick 执行
function monthlyResourceTick():
    performance = clamp(performance + computePerformanceDelta(), 0, 100)
    connections = clamp(connections + computeConnectionsDelta(), 0, 100)
    budget = max(0, budget + computeBudgetDelta())
```

### 政绩阈值判定

```
function getPerformanceStatus(score):
    if score <= 20: return "危险"
    if score <= 40: return "警告"
    if score <= 60: return "合格"
    if score <= 80: return "良好"
    return "卓越"
```

## Edge Cases

| Scenario | Expected Behavior | Rationale |
|----------|------------------|-----------|
| 政绩跌到 0 | 触发问责事件——可能被调离、降级甚至免职。政绩不再降低（0为下限） | 已经到底了，再差就是组织处理 |
| 人脉跌到 0 | 所有 NPC 态度降至冷淡/负面。无法求人办事。重建人脉需要从零开始 | 你在官场「社死」了 |
| 财力归零 | 项目无法推进、无法社交维护关系。下个月常规预算会恢复一些 | 没钱寸步难行，但你是公务员，有薪水兜底 |
| 灰色收入导致财力和政绩矛盾 | 灰色收入增加财力但增加暴露风险→政绩受威胁。玩家需要权衡 | 灰色地带的本质：短期利益 vs 长期安全 |
| 多个项目并行消耗资源 | 财力按项目优先级分配。如果不够，低优先级项目进度暂停 | 同时推进太多事情会资源枯竭 |

## Dependencies

| System | Direction | Nature of Dependency |
|--------|-----------|---------------------|
| 时间系统 | 资源依赖时间 | 每月 tick 触发资源结算 |

**下游依赖**：

| System | Nature of Dependency |
|--------|---------------------|
| 月度经营系统 | 读取资源值用于显示和决策 |
| 考核系统 | 读取政绩值用于考核计算 |
| 事件系统 | 读取资源值作为事件触发条件 |
| 灰色地带系统 | 读取/修改财力和政绩 |
| 关系网络系统 | 人脉值与个体 NPC 态度互相影响 |
| 晋升系统 | 读取政绩值作为晋升条件 |
| 主面板 UI | 显示三个资源值 |
| 数据持久化 | 序列化/反序列化资源数据 |

## Tuning Knobs

| Parameter | Default | Safe Range | Effect of Increase | Effect of Decrease |
|-----------|---------|------------|-------------------|-------------------|
| 月度自然衰减（人脉） | -2/月 | -1 to -5/月 | 关系冷得更快——更需要主动维护 | 关系持久——社交压力变小 |
| 政绩阈值（良好） | 60 | 50-75 | 更难获得「良好」评价 | 更容易被认为「良好」 |
| 政绩阈值（卓越） | 80 | 70-90 | 更难成为明星干部 | 更容易脱颖而出 |
| 灰色收入风险系数 | 见灰色地带系统 | — | 灰色收入更容易暴露 | 灰色操作更安全 |
| 财力→人脉转化率 | 20财力=1人脉 | 10-40 | 交朋友更贵 | 交朋友更便宜 |

## Acceptance Criteria

- [ ] 三个资源可正确追踪、更新和显示
- [ ] 政绩阈值正确判定状态（危险/警告/合格/良好/卓越）
- [ ] 人脉月度自然衰减生效
- [ ] 财力不低于0
- [ ] 所有资源产出和消耗来源可追溯（不是神秘的数字变动）
- [ ] 灰色收入正确增加财力
- [ ] 资源数据可正确序列化到存档

## Open Questions

| Question | Status | Notes |
|----------|--------|-------|
| 是否需要增加「健康」/「精力」资源？ | 后续 | 增加压力维度，限制玩家同时推进太多事情 |
| 人脉值是否应该按领域拆分（商界人脉、政界人脉、学界人脉）？ | MVP 不拆 | MVP 用聚合值，后期可扩展 |
| 财力是否使用具体货币数值（万元）？ | MVP 使用抽象数值 | 避免绑定真实物价和汇率，更灵活 |
