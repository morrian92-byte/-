# 灰色地带系统

> **Status**: In Design | **Layer**: `Feature` | **Priority**: `MVP` | **Deps**: `资源系统`, `NPC 系统`, `事件系统`
> **Pillar**: 灰色即深度（灰色地带是官场深度的核心体现）

## Overview

灰色地带系统管理所有「不违反明文规定但也不清白」的操作——从收一条烟到吃工程回扣。它不做道德审判，只管理三个变量：**腐败风险**、**腐败收益**、**暴露概率**。不同环境（年代、岗位、监管强度）影响这三个变量，衍生出不同的生存策略。

## Detailed Design

### 腐败操作分类

| 级别 | 操作举例 | 收益 | 暴露风险 | 后果 |
|------|---------|------|---------|------|
| 轻微 | 收条烟、吃顿饭、报销多报几百 | 小 | 极低 | 约谈提醒 |
| 中等 | 收购物卡礼品、安排亲属工作、工程关照 | 中 | 低-中 | 警告/记过 |
| 严重 | 工程回扣、土地利益输送、买官卖官 | 大 | 中-高 | 撤职/调查 |
| 极严重 | 组织贪腐、保护伞、巨额贿赂 | 极大 | 高 | 双规/刑事 |

### 风险模型

```
exposure_probability = 
    base_risk[operation_level] 
    * era_modifier          // 不同年代基础风险不同
    * supervision_modifier  // 监管强度（巡视期间翻倍）
    * corruption_history_modifier  // 屡犯者更容易暴露
    * npc_modifier          // 被正直 NPC 发现概率更高
```

### 环境差异

| 环境 | 腐败风险 | 说明 |
|------|---------|------|
| 基建/工程岗 | 高 | 项目资金流大，机会多 |
| 教育/文化岗 | 低 | 利益空间小 |
| 组织/人事岗 | 中等 | 人情关系而非金钱 |
| 财政/审计岗 | 高 | 掌握钱袋子 |
| 公检法岗 | 极高 | 权力大，但被抓后果也最严重 |

### 腐败后果

**未被发现**：收益高，但风险种子已种下（连锁事件）
**被发现**：
1. 轻微→约谈提醒（政绩-5，人脉-3）
2. 中等→警告/记过（政绩-15，影响晋升）
3. 严重→撤职调查（职级可能降级）
4. 极严重→双规/刑事（仕途终结）

## Formulas

```
gray_risk_level = computeRisk(corruption_history, supervision_intensity, npcs_nearby)
// 每次灰色操作后: risk_seed_planted = true
// 每月: if risk_seed: check_exposure()
```

## Edge Cases

- 连续多次轻微腐败：风险累积加速（+20%/次）
- 巡视期间腐败操作：暴露概率 ×2.5

## Acceptance Criteria

- [ ] 腐败操作按级别分类，不同风险
- [ ] 环境差异影响风险
- [ ] 暴露概率受多重因素影响
- [ ] 暴露后后果与操作级别匹配
