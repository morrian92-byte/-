# 月度经营系统

> **Status**: In Design | **Layer**: `Core` | **Priority**: `MVP` | **Deps**: `时间系统`, `资源系统`
> **Pillar**: 权力是积累的 + 关系即游戏

## Overview

月度经营系统是核心循环的引擎——它定义了玩家每个月「做什么」。每月初，玩家获得 3 个 **行动点**，可以在政务、关系、事件应对之间分配。月末结算，看到结果，进入下一个月。

## Detailed Design

### 行动点机制

| 参数 | 值 |
|------|-----|
| 每月行动点 | 3（MVP 固定） |
| 每点可做的事 | 推进项目 / 社交 / 应对事件 / 其他 |
| 未使用的行动点 | 不累积到下月 |

### 每月可选行动

**政务类（消耗 1 行动点）**：
| 行动 | 效果 | 消耗 |
|------|------|------|
| 推进项目 | 选中项目的进度+1 | 项目月度财力消耗 |
| 加速项目 | 进度额外+1 | 双倍财力消耗 |
| 启动新项目 | 创建新项目 | 项目启动资金 |
| 常规工作 | 政绩+1~2 | 无 |

**关系类（消耗 1 行动点）**：
| 行动 | 效果 | 消耗 |
|------|------|------|
| 请客吃饭 | 目标 NPC 态度+3~8 | 财力 5-20 |
| 拜访汇报 | 目标 NPC 态度+2~5 | 无财力消耗 |
| 送礼 | 目标 NPC 态度+5~15 | 财力 10-50 |
| 帮 NPC 的忙 | 目标 NPC 态度+8~20 | 视情况 |
| 参加集体活动 | 在场所有 NPC 态度+1~3 | 财力 3-10 |

**应对类（消耗 1 行动点）**：
| 行动 | 效果 |
|------|------|
| 处理待办事件 | 每个待处理事件视选项消耗 1 行动点 |

### 月度流程

```
月初 → 查看面板（资源、项目、关系状态）
     → 选择 3 个行动（可全政务/全关系/混合）
     → 事件检查（可能触发新事件）
     → 月末结算（项目进度+1、资源变化、关系衰减）
     → 考核检查（月底/季末/年末）
     → 玩家点击「结束本月」
```

### 行动约束

- **精力限制**：同时只能推进 3 个以内项目（与行动点数一致）
- **信息限制**：不是所有事件选项都可见——需要对应人脉 ≥ 某个值才能看到某些选项
- **财力限制**：社交行动需要足够财力支撑

## Edge Cases

- 0 财力：社交类行动不可用（没钱请客），只能拜访汇报
- 所有 3 点都用在危机上：正常政务/社交本月为零推进

## Dependencies

上行：时间系统、资源系统
下行：项目管理、关系网络、事件系统、考核系统、UI

## Acceptance Criteria

- [ ] 每月 3 个行动点可正确分配
- [ ] 政务行动推进项目进度
- [ ] 社交行动改变 NPC 态度
- [ ] 财力不足时社交选项受限
- [ ] 月末正确触发结算
