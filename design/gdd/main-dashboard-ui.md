# 主面板 UI

> **Status**: In Design | **Layer**: `UI` | **Priority**: `MVP` | **Deps**: `月度经营系统`, `资源系统`

## Overview

主面板是玩家 90% 时间面对的界面。它整合了所有核心信息——资源、NPC、项目、事件入口——同时保持信息密度可控。设计原则：**一屏尽览，三秒定位**。

## Layout（桌面端优先）

```
┌─────────────────────────────────────────────────┐
│ 2022年6月 | 新时代 | 副股级 | 张三 | 年龄26      │ ← 顶栏
├────────────┬───────────────────┬────────────────┤
│  资源面板   │                   │  关键人物        │
│ 政绩 65 ●  │   本月待办         │ 张书记 +35 🟢   │
│ 人脉 42 ●  │                  │ 李副书记 -15 🟠  │
│ 财力 320  │  [推进项目]        │ 王主任 +72 🟢   │
│            │  [社交活动]        │ 赵股长 +10 ⚪   │
│  项目进度   │  [应对事件]        │                │
│ 路 5/8 ▓▓  │                  │                 │
│ 厂 2/6 ▓   │  最近事件          │                │
│            │  ⚡ 上面要来检查     │                │
├────────────┴───────────────────┴────────────────┤

└─────────────────────────────────────────────────┘
```

## 核心组件

| 组件 | 内容 | 交互 |
|------|------|------|
| 顶栏 | 日期、年代、职级、姓名、年龄 | 点击姓名→人物档案 |
| 资源面板 | 政绩/人脉/财力数值+状态标签 | 悬停→详细 breakdown |
| 行动面板 | 3个行动点，每点可选政务/关系/应对 | 点击→弹出可选行动列表 |
| 项目进度 | 活跃项目的进度条 | 点击→项目详情 |
| NPC 列表 | 最近互动的 5 个 NPC + 态度条 | 点击→NPC 详情 |
| 事件入口 | 待处理事件数+最新事件标题 | 点击→事件面板 |
|「结束本月」| 推进到下一个月 | 危机时灰显 |
