# 事件面板 UI

> **Status**: In Design | **Layer**: `UI` | **Priority**: `MVP` | **Deps**: `事件系统`

## Overview

事件面板是玩家处理官场事件的界面。它通常以弹窗/叠加层的形式出现在主面板之上，呈现事件描述、可选项和后果预览。危机模式下，事件面板包含倒计时。

## 布局

```
┌──────────────────────────────────┐
│ ⚡ 群众举报违规建筑          [X]  │ ← 标题栏（危机+倒计时）
├──────────────────────────────────┤
│                                  │
│  [企业主张大富]在[东风村]违规     │ ← 叙事文本
│  建设工业厂房，占地约[5亩]。      │    （参数填充）
│  群众[12]人联名举报至镇纪委。     │
│                                  │
│  你在其中牵涉：[无直接关联]       │ ← 个人关联度
│                                  │
├──────────────────────────────────┤
│                                  │
│  ○ A) 秉公处理——转纪委立案       │ ← 选项
│     后果：张对你的态度 -30        │
│     风险：无                      │
│                                  │
│  ● B) 私下调解——劝张补办手续     │
│     后果：张对你的态度 +15        │
│     财力：-10（调解费）           │
│     风险：★☆☆（举报人可能不满）  │
│                                  │
│  ○ C) 压下来——给纪委打招呼       │
│     后果：张对你的态度 +25        │
│     财力：-30                     │
│     风险：★★★（巡视期间高风险）  │
│     条件：需要人脉 ≥ 50           │ ← 锁定选项
│                                  │
├──────────────────────────────────┤
│                     [确认选择]    │
└──────────────────────────────────┘
```

## 核心规则

- 危机事件：标题栏显示倒计时（60秒默认）
- 锁定选项：不满足条件时灰显，显示缺失条件
- 风险星标：★☆☆ 到 ★★★表示暴露风险
- 后果预览：每个选项显示已知后果（不保证完全准确——有些连锁后果不可预见）
- 选择确认：点击选项后亮起，点击「确认选择」才生效

## Acceptance Criteria

- [ ] 事件描述参数化填充正确
- [ ] 选项按条件锁定/解锁
- [ ] 危机事件倒计时正确
- [ ] 风险星标显示
- [ ] 选择确认后正确传递后果到各系统
