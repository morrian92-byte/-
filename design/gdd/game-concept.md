# Game Concept: 步步高升

*Created: 2026-06-09*
*Status: Draft*

## Elevator Pitch

> 一款以现代中国官场为背景的策略模拟游戏。你从乡镇基层公务员起步，在真实的职级体系、复杂的派系关系和灰色的道德地带中，用一生的时间经营你的政治生涯。没有标准的好结局或坏结局——只有你选择的为官之道。

## Core Fantasy

**权力是可以「品尝」的。**

玩家在这个游戏中体验的不是打怪升级的快感，而是权力本身的味道——积累资源的满足感、信息不对等的优越感、别人对你态度变化的微妙快感、以及在灰色地带走钢丝的刺激。

现实中触碰不到的权力滋味，在这里可以沉浸式体验。每一次晋升都不是一个简单的新称号，而是一个更大的舞台、更复杂的博弈、和更深不可测的风险。

游戏的情感承诺：**你会对权力上瘾。**

---

## Unique Hook

> 「它像《模拟人生》的沉浸式经营，也像策略游戏的资源积累，**但它还**拥有真实的中国政治体系——执政党与参政党的权衡、政务岗与党务岗的双轨晋升、灰色地带的生存智慧——这不是西方政治模拟的翻译版，而是从中国官场土壤里长出来的游戏。」

## Player Experience Analysis (MDA Framework)

### Target Aesthetics (What the player FEELS)

| Aesthetic | Priority | How We Deliver It |
| ---- | ---- | ---- |
| **Fantasy** (make-believe, role-playing) | 1 | 真实的中国官场沉浸——职级、关系、事件全部基于现实体系 |
| **Narrative** (drama, story arc) | 2 | 系统驱动的动态叙事——每个玩家的政治生涯都是独一无二的故事 |
| **Expression** (self-expression, creativity) | 3 | 无「正确答案」——清官、能臣、贪官、庸吏，你定义自己的为官之道 |
| **Challenge** (obstacle course, mastery) | 4 | 复杂的晋升博弈——指标是底线，关系是天花板，机遇是变量 |
| **Discovery** (exploration, secrets) | 5 | 灰色系统中的隐藏规则——不同环境的不同生存法则 |
| **Submission** (relaxation, comfort zone) | 6 | 回合制节奏允许玩家按自己的步调思考和决策 |
| **Sensation** (sensory pleasure) | N/A | 文字为主，视觉为辅 |
| **Fellowship** (social connection) | N/A | 单人游戏 |

### Key Dynamics (Emergent player behaviors)

- 玩家会自发地在「干实事」和「搞关系」之间寻找平衡点
- 玩家会形成自己独特的腐败伦理——在哪里画线、什么时候破例
- 玩家会对特定 NPC 产生真实的情感依附或厌恶
- 玩家会反复尝试不同的晋升策略，探索系统的边界
- 玩家之间会分享各自的「政治生涯故事」

### Core Mechanics (Systems we build)

1. **月度回合制经营系统**：每月分配精力在政务、关系、应对事件之间
2. **关系网络系统**：NPC 对你的态度因行为而变化，关系网络影响信息和机会
3. **事件生成系统**：巡视、举报、舆情、项目推进——系统驱动而非手写
4. **双轨晋升系统**：行政职级+党务岗位，真实职级体系
5. **灰色地带系统**：不同岗位/地区的腐败风险不同，环境决定策略

## Player Motivation Profile

### Primary Psychological Needs Served

| Need | How This Game Satisfies It | Strength |
| ---- | ---- | ---- |
| **Autonomy** (freedom, meaningful choice) | 无标准结局——清官、贪官、能臣、庸吏都是合法路线；选择加入哪个党派或不加入；在灰色地带自己画线 | Core |
| **Competence** (mastery, skill growth) | 从科员到厅级甚至更高，每一步都看得见成长；政绩、人脉、影响力都在膨胀 | Core |
| **Relatedness** (connection, belonging) | 复杂的 NPC 关系网——领导、同僚、下属、商人、群众，每段关系都会因你的行为而演变 | Supporting |

### Player Type Appeal (Bartle Taxonomy)

- [x] **Achievers** (goal completion, collection, progression) — How: 职级晋升、资源积累、政绩指标
- [x] **Explorers** (discovery, understanding systems, finding secrets) — How: 灰色系统的隐藏规则、不同路径的后果、NPC 关系网的深层逻辑
- [ ] **Socializers** (relationships, cooperation, community) — N/A: 单人游戏
- [ ] **Killers/Competitors** (domination, PvP, leaderboards) — N/A: 无竞争元素

### Flow State Design

- **Onboarding curve**：前 3 个月（游戏时间）为引导期，系统逐步开放，像真实新人一样边学边干
- **Difficulty scaling**：晋升越往上越难——竞争更激烈、关系更复杂、风险更大。挑战随玩家权力增长而升级
- **Feedback clarity**：月度汇报、年度考核、NPC 态度变化——多层次反馈让玩家清楚自己的处境
- **Recovery from failure**：仕途受挫不等于游戏结束——处分、降级、调离都是故事的一部分，不是 Game Over

## Core Loop

### Moment-to-Moment (30 seconds — 一个游戏月)

月初查看待办：
- **政务决策**：本月推进哪几个项目？预算怎么分配？（2-3 个选择）
- **关系维护**：该见谁、该回谁的信息、该赴谁的约（选重点，不能全顾）
- **突发应对**：抽查、信访、舆情、竞争对手的动作——打断你的计划

月末结算——数字变化、人物态度变化、新事件解锁。

### Short-Term (5-15 minutes — 一个季度)

季度是项目里程碑节点：
- 项目进度汇报
- 季度考核小汇总
- 关系网络的季度变化
- 新事件和机遇的出现
- 「再来一个月」的心理触发点

### Session-Level (30-120 minutes — 一个游戏年)

年底是关键时刻：
- **年度考核**：指标过线了吗？（不过线问责，过线才有晋升资格）
- **人事变动**：有没有空位置？上面有没有人替你说话？
- **大事件密集期**：巡视组、重要会议、派系博弈集中爆发
- 年底自然是一个「存档点」——也是让玩家惦记「明年会发生什么」的钩子

### Long-Term Progression

一个完整的政治生涯跨度 **20-30 年（240-360 个月回合）**：

```
科员 → 副科 → 正科 → 副处 → 正处 → 副厅 → 正厅 → 副部 → 正部 → 副国 → 正国
 |       |       |       |       |       |       |
 └─乡镇   └─乡镇   └─县级   └─县级   └─市级   └─市级   └─省级以上...

常态晋升节奏：每级 3-5 年
破格提拔：政绩极突出 + 关键人物力推 + 刚好有空缺 → 极罕见（<5% 概率）
```

层级分布（贴合现实）：
| 层级 | 大致占比 | 说明 |
|------|---------|------|
| 科级及以下 | ~60% | 绝大多数人的天花板 |
| 处级 | ~25% | 县级主官，已经是百里挑一 |
| 厅级 | ~10% | 市级领导，人中龙凤 |
| 部级 | ~4% | 省级/部委，极少数能企及 |
| 国家级 | ~1% | 凤毛麟角 |

### Retention Hooks

- **Investment**：积累的政绩、经营的人脉、塑造的政治人格——每一步都有持久影响，无法「重来一遍」
- **Curiosity**：下一级会解锁什么？灰色地带会怎样演变？那个 NPC 到底站在哪一边？
- **Mastery**：每次重开尝试不同的策略——这次做清官，下次试试灰色路线，再下次玩民主党派
- **Story**：系统生成的独特政治生涯——没有两局是相同的

## Game Pillars

### Pillar 1: 权力是积累的

每一分人脉、每一笔政绩、每一次站队，都会留下持久的痕迹。没有重来，没有清零。你今天的每一个选择都在为明天的权力铺路——或者挖坑。

*Design test*：如果我们在讨论一个功能时犹豫，「它是否会留下持久的影响？」

### Pillar 2: 关系即游戏

官场不是一个人的战斗。领导、同僚、下属、商人、群众——你对每个人的态度、你与每个人的利益交换，构成了真正的游戏棋盘。数字只是表面，关系才是底层。

*Design test*：「这个系统里，人际关系是否在起作用？是否能产生有意义的后果？」

### Pillar 3: 灰色即深度

没有黑白分明的道德选择。每个环境有不同的规则，每笔交易有不同的价码。游戏不做道德审判，只呈现后果。玩家自己定义底线在哪里。

*Design test*：「这个决策是否让人犹豫？是否没有明显的『正确』答案？」

### Anti-Pillars (What This Game Is NOT)

- **NOT 爽文套路**：不会出现「贪污永不被发现」或「清官必然高升」的童话逻辑。每种选择都有代价，没有无风险的高回报。
- **NOT 数值碾压**：你不能靠堆数字就赢。关系不是用钱就能买通的，政绩不是刷数据就能解决的。系统会制造真实的阻力和反噬。
- **NOT 一次性叙事**：没有预设的主线剧情。你的官场故事是系统生成的——由你的起点、你的选择、你遇到的事件和人物共同编织。每次重开都是不同的人生。

## Risks and Open Questions

### Design Risks

- **核心循环可能不够上瘾**：月度回合制的节奏是否足够吸引人？需要通过 MVP 验证
- **「灰色地带」可能让部分玩家不适**：不做道德审判可能被误读为鼓励腐败
- **文字量可能显得枯燥**：需要在 UI 设计和信息呈现上下功夫

### Technical Risks

- **事件生成系统可能产生重复感**：需要设计足够多的参数维度和组合逻辑
- **关系网络的复杂度可能失控**：NPC 数量增长后，关系变化的计算量可能呈指数增长

### Scope Risks

- **「全仕途骨架」野心大**：从科员到国家级跨度极大，需要严格按 MVP 分阶段交付
- **内容调校时间长**：晋升节奏、腐败风险、关系权重——这些数值需要大量测试才能平衡

### Open Questions

- 是否加入家族/家庭维度（配偶、子女对仕途的影响）？→ 可在 MVP 后评估
- 是否加入跨局继承（上一局积累的资源影响下一局的起点）？→ 与「无清零」支柱契合，可作为 Progression 阶段功能
- 多人模式（官场中与其他玩家互动）？→ 技术复杂度高，目前暂不考虑

## MVP Definition

**Core hypothesis**：玩家会在「政务 vs 关系 vs 灰色地带」的月度经营循环中找到持续的动力——他们会上瘾于权力的积累和人脉的经营。

**Required for MVP**（乡镇人生版）：
1. **乡镇级单一场景**——一个乡镇、一个核心岗位（副科到正科）、约 5 年游戏时间（60 个月回合）
2. **基础资源系统**——政绩、人脉、财力三个核心资源
3. **关系网络**——8-12 个关键 NPC（镇长、书记、同僚、下属、商人、群众代表），态度随行为变化
4. **事件系统**——10-15 个核心事件模板，系统参数化生成
5. **月度考核 + 年度考核**——基础晋升机制，不包含破格提拔
6. **基础灰色地带**——乡镇环境下的腐败风险与机会
7. **Web 界面**——纯文字+数据面板

**Explicitly NOT in MVP**（后续版本）：
- 县级及以上层级
- 党派系统（执政党/民主党派/无党派选择）
- 党务岗位双轨
- 破格提拔机制
- 跨局继承
- 家族系统

### Scope Tiers

| Tier | Content | Features | Timeline |
| ---- | ---- | ---- | ---- |
| **MVP** | 一个乡镇，副科→正科，5年 | 基础资源+关系+事件+考核 | 2-3 月 |
| **Vertical Slice** | 乡镇+县级，副科→正处，10年 | +党派选择+灰色深化+破格提拔 | +3-4 月 |
| **Alpha** | 全层级骨架（科员→厅级），20年 | 全系统就位，内容待填充 | +4-6 月 |
| **Full Vision** | 科员→国家级，30年，所有党派路线 | 全系统+全事件+全 NPC 原型+平衡调校 | +6-12 月 |
