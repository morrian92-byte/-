# 时间系统

> **Status**: In Design
> **Author**: Player + Claude
> **Last Updated**: 2026-06-09
> **Implements Pillar**: 权力是积累的（时间是积累发生的维度）

> **Quick reference** — Layer: `Foundation` · Priority: `MVP` · Key deps: `None`

## Overview

时间系统是《步步高升》的基础节拍器。它以「月」为最小时间单位驱动游戏世界：每回合代表一个月，12个月构成一年，一个完整的政治生涯跨越约 20-30 年（240-360 个回合）。

时间推进采用**混合模式**：
- **日常回合**：玩家手动点击「结束本月」推进时间，完全控制自己的节奏——查看数据、权衡决策、阅读事件，想多久就多久。
- **危机时刻**：当突发事件触发（巡视突击、实名举报、重大事故），时间自动暂停，进入紧张模式——玩家必须在有限时间内做出响应，然后时间恢复。

时间系统的每一次 tick（月份推进）都会触发所有依赖系统的结算：资源产出/消耗、关系衰减、项目进度、事件检查、考核判定。它不只是一个计数器——它定义了这个世界的节奏，而「不可逆转」的特性让每一回合的决策都有了重量。

## Player Fantasy

时间不是一条均匀的传送带。在日常治理中，时间是可控的——你坐在办公室里，从容地审批文件、安排项目、维护关系。但在风暴来临时，时间的质感骤变——巡视组的电话、纪检的通知、网络舆情的爆发，每件事都在倒计时，你必须快速判断。

时间的不可逆性也是权力幻想的一部分：你做的每一个选择都被时间锁定了。今天推掉的项目、得罪的人、收下的好处——它们不会消失，它们会跟着时间一起走向未来。这种「一切都有后果」的感觉，正是支柱「权力是积累的」在时间维度上的体现。

## Detailed Design

### Core Rules

**R1 — 时间单位**：游戏的最小时间单位为 1 个月。所有计时、结算、触发均以月为基准。

**R2 — 月份推进**：
- 日常模式下，玩家手动点击「结束本月」推进时间。
- 当存在待处理的危机事件时，「结束本月」被禁用，玩家必须先处理危机。

**R3 — 年度轮转**：12月结束后，年份+1，月份重置为1。年度轮转触发年度考核、年度事件和年龄增长。

**R4 — 季度**：每3个月构成1个季度（Q1: 1-3月, Q2: 4-6月, Q3: 7-9月, Q4: 10-12月）。季度触发项目里程碑检查和季度考核汇总。

**R5 — 起始年代选择**：游戏开始时，玩家从 7 个年代中选择一个作为起始时间点。不同年代影响基础参数：

| 年代 | 时间范围 | 特征 |
|------|---------|------|
| 建国初期 | ~1950s-1965 | 计划经济、政治运动初起、干部制度草创——阶级斗争开始影响仕途 |
| 文革时期 | ~1966-1976 | 政治挂帅、派系极端化、正常工作秩序被打乱——最高风险的年代 |
| 拨乱反正 | ~1977-1983 | 文革后重建、平反冤假错案、老干部复出——承前启后的过渡期 |
| 改革开放初期 | ~1984-1992 | 南巡讲话、市场经济萌芽、双轨制——规则模糊，机会爆炸 |
| 市场经济时代 | ~1993-2005 | 高速发展、体制逐步规范、GDP 挂帅——黄金发展期 |
| 新世纪 | ~2006-2015 | 规则收紧、巡视常态化、考核多元化——新旧交替 |
| 新时代 | ~2016至今 | 全面从严、反腐高压、终身追责——最高难度 |

不同年代的 GDP 增长基线、腐败风险系数、事件类型权重不同。年代不影响核心机制，只影响参数和事件内容。

**R6 — 年龄与退休**：
- 玩家角色起始年龄：根据起始职级设定（科员通常22-25岁）。
- 每年1月年龄+1。
- **正常退休**：年满60岁触发退休流程，仕途终结。
- **提前终结**（以下任一条件触发）：
  - 双规/留置调查后定罪
  - 撤职且无复出机会
  - 重大疾病事件
  - 刑事追究

**R7 — 任期追踪**：
- 每个岗位的标准任期为 5 年（60个月）。
- 任期满前3个月，系统触发「任期将满」提示。
- 任期满时触发任期结算——根据考核结果和关系状态，判定留任、平调或晋升。
- 如果在任期内被处分/调离，任期重置为新岗位的5年倒计时。

**R8 — 时间不可逆**：不存在「回溯」或「读档到上个月」。玩家可以手动存档，但加载存档只能加载已保存的时间点。在当前回合内取消操作可以回到月初状态，但一旦推进到下一月，上一月的决策就锁定了。

### States and Transitions

| State | Entry Condition | Exit Condition | Behavior |
|-------|----------------|----------------|----------|
| NORMAL | 月初自动进入 | 玩家点击「结束本月」 | 可自由查看数据、做决策、触发非危机事件 |
| CRISIS_PAUSED | 危机事件触发（巡视、举报、事故等） | 玩家做出危机响应决策 | 时间冻结，「结束本月」禁用。强制在有限选项中选择 |
| YEAR_END | 12月结束 | 年度结算完成后自动转入1月 NORMAL | 触发年度考核、年度事件、年龄增长 |
| TERM_END | 任期倒数第3个月开始标记 | 任期结算完成 | 触发留任/晋升/平调判定 |
| CAREER_END | 退休/免职/定罪等 | — | 游戏结束，展示仕途总结 |

**State Transition Diagram**:
```
NORMAL ──(click 结束本月)──> [check: 最后一个月?] ──Yes──> YEAR_END ──> NORMAL
    │                            │
    │                            No
    │                            ↓
    │                         [check: 任期快到了?] ──Yes──> TERM_END ──> NORMAL
    │                            │
    │                            No
    │                            ↓
    │                         NORMAL (next month)
    │
    └──(crisis triggers)──> CRISIS_PAUSED ──(resolve)──> NORMAL
```

## Formulas

### 基础时间计算

```
total_months = (current_year - start_year) × 12 + (current_month - start_month)
current_age = start_age + floor(years_passed)
years_passed = current_year - start_year
current_quarter = ceil(current_month / 3)
```

### 任期计算

```
term_months_elapsed = total_months - term_start_month
term_months_remaining = 60 - term_months_elapsed
is_term_ending = term_months_remaining ≤ 3 AND term_months_remaining > 0
is_term_expired = term_months_remaining ≤ 0
```

### 退休判定

```
is_retirement_age = current_age ≥ 60
career_months_remaining = max(0, (60 - current_age) × 12)
```

所有公式中，变量类型均为整数。月份范围 1-12。年龄在每年1月递增。

## Edge Cases

| Scenario | Expected Behavior | Rationale |
|----------|------------------|-----------|
| 危机事件在 YEAR_END 期间触发 | 先完成年度结算，危机在新年1月初触发 | 年度考核是制度性流程，不被打断 |
| 危机事件在 TERM_END 期间触发 | 任期结算完成，危机随后触发 | 人事决定后再面对危机，更有戏剧性 |
| 玩家满60岁但晋升/调任审批中 | 批准后执行调动，然后在新的1月初自动退休（至少度过当前年） | 给玩家一个「最后的安排」 |
|「结束本月」可以撤销吗？ | 在 NORMAL 状态下，如果尚未做任何不可逆操作，可以取消回到月初。一旦做了不可逆操作（如收受贿赂、签署决定），不可撤销 | 保护玩家免受误操作，同时保证关键决策的严肃性 |
| 危机事件同时触发多个 | 按优先级排队：巡视/纪检 > 重大事故 > 舆情 > 其他。玩家逐一处理 | 避免信息过载 |
| 闰年 | 不处理。最小时间单位为月，不受闰年影响 | 月份级精度不需要日级复杂度 |
| 年代切换时参数突变 | 年代切换是渐进的——每进入新的十年（如1990→2000），参数按插值平滑过渡，而非跳变 | 避免玩家利用年代切换的规则跳变进行博弈 |

## Tuning Knobs

| Parameter | Default | Safe Range | Effect of Increase | Effect of Decrease |
|-----------|---------|------------|-------------------|-------------------|
| 退休年龄 | 60 | 55-65 | 更长的仕途，更多回合——降低紧迫感 | 更短的仕途——增加压力和紧凑感 |
| 标准任期 | 60月(5年) | 36-72月 | 每级停留更久——晋升更慢，更真实但可能枯燥 | 晋升更快——节奏快但不太真实 |
| 任期预警 | 3月 | 1-6月 | 更早获得「任期将满」信号——更多准备时间 | 更突然——增加临场压力 |
| 危机决策时限 | 60秒 | 30-120秒 | 更从容——适合新手 | 更有压迫感——适合老手 |
| 年龄惩罚阈值 | 50岁 | 45-55岁 | 年龄歧视更晚出现——高层仍有竞争力 | 更早感受到年龄天花板 |

## Acceptance Criteria

- [ ] 点击「结束本月」后，月份+1；12月结束后年份+1且月份重置
- [ ] 每年1月，角色年龄+1
- [ ] 危机事件触发时，时间自动暂停，「结束本月」按钮不可用
- [ ] 处理完所有危机后，「结束本月」按钮恢复
- [ ] 任期剩余≤3个月时，界面有预警提示
- [ ] 角色年满60岁时，触发退休流程
- [ ] 可正常存档/读档，恢复正确的时间状态
- [ ] 起始年代选择影响参数（验证：不同年代有不同 GDP 增长基线）
- [ ] 所有下游系统正确接收到每月 tick 信号
